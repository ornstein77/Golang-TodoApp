TodoApp
Веб-приложение для работы со списком задач. Серверная часть написана на Go, данные хранятся в PostgreSQL. Проект содержит код приложения, SQL-миграции, публичные файлы, документацию Swagger и конфигурацию для запуска с помощью Docker Compose.
Структура проекта
cmd/
  todoapp/        # точка входа и файлы для сборки приложения
docs/             # документация Swagger
internal/         # внутренняя логика приложения
migrations/       # SQL-миграции базы данных
public/           # публичные файлы приложения
out/
  logs/           # журналы приложения
  pgdata/         # данные PostgreSQL
.env.example      # пример файла с настройками окружения
Makefile          # команды для запуска и обслуживания проекта
docker-compose.yaml
go.mod            # модуль Go и прямые зависимости
go.sum            # контрольные суммы зависимостей
Используемые технологии
- Go 1.25.5 — язык программирования серверной части.
- PostgreSQL 18.4 — система управления базой данных.
- pgx/v5 — библиотека для подключения Go-приложения к PostgreSQL.
- golang-migrate — создание и применение миграций базы данных.
- Docker Compose — запуск приложения и вспомогательных сервисов.
- Swagger / OpenAPI — описание API.
- validator — проверка входящих данных.
- envconfig — загрузка настроек из переменных окружения.
- zap — структурированное журналирование.
- UUID — работа с универсальными идентификаторами.
Настройка
Перед запуском необходимо создать файл .env на основе .env.example и указать параметры подключения к PostgreSQL:
POSTGRES_USER=
POSTGRES_PASSWORD=
POSTGRES_DB=
Дополнительные параметры приложения задаются через переменные окружения. В конфигурации Docker Compose используются адрес и порт HTTP-сервера, параметры подключения к базе данных, уровень логирования, часовой пояс и путь для файлов журналов.
Запуск проекта
Запуск PostgreSQL
make env-up
Запуск перенаправления порта PostgreSQL
make env-port-forward
Применение миграций
make migrate-up
Запуск приложения
make todoapp-run
После запуска HTTP-сервер доступен на порту 5050.
Запуск через Docker Compose
Для сборки и запуска приложения в контейнере используется команда:
make todoapp-deploy
Остановка контейнера приложения:
make todoapp-undeploy
Проверить состояние сервисов можно командой:
make ps
Миграции базы данных
Файлы миграций находятся в каталоге migrations/. Для создания новой миграции предусмотрена команда:
make migrate-create seq=название_миграции
Применение миграций:
make migrate-up
Откат миграций:
make migrate-down
Документация API
Документация API формируется с помощью Swagger на основе аннотаций в исходном коде. Для её генерации используется команда:
make swagger-gen
Сгенерированные файлы документации размещаются в каталоге docs/.
Журналирование
Файлы журналов приложения сохраняются в каталоге out/logs. Уровень логирования и путь к каталогу задаются через переменные окружения и настройки Docker Compose.
Основные возможности проекта
- запуск HTTP-приложения на Go;
- подключение к базе данных PostgreSQL;
- управление изменениями схемы базы данных с помощью миграций;
- проверка входящих данных;
- ведение журналов работы приложения;
- генерация документации API в формате Swagger;
- запуск приложения и базы данных с помощью Docker Compose.
